# CatchIt 🎬

Instagram 热门视频**搬运工作台**：发现 IG 最近一周的热门视频 → 勾选下载 → 写文案 → 手动发布到小红书/抖音并跟踪状态。全部在本地运行，数据存在本地 SQLite。

```
发现（抓取热门 / 粘贴链接） → 下载入库 → 素材库写文案 → 标记已发（小红书 / 抖音）
```

## 功能

- **抓取热门**：按「主题频道」采集（Reels 流 + Explore 页 + 频道配置的标签页），拦截页面 JSON 接口解析视频数据，本地按互动分（点赞 + 3×评论 + 0.01×播放）排序，过滤出最近 7 天发布、未入库的视频，取 Top 50 进「发现」页。
- **粘贴链接下载**：顶部输入框粘贴任意 Instagram 视频链接（可一次多条），自动解析元数据、入库并下载——在 IG 上刷到感兴趣的视频直接贴过来。
- **素材库**：已下载视频内嵌播放预览；每条可写自己的小红书/抖音文案（自动保存）、一键复制原作者出处、标记「已发小红书」「已发抖音」，支持按待发/已发筛选，避免重复发布。
- **下载**：内置 yt-dlp（自动带登录 cookie），保存到 `videos/<当天日期>/`；失败的视频集中在「失败」页，可重试或用 savefrom.net 备用链接手动下载。
- **去重**：所有见过的视频记录在数据库，抓取和粘贴都不会重复出现；不想要的可「忽略」。
- **任务可控**：抓取/下载/登录任务都显示实时进度，随时可取消。

> ⚠️ Instagram 不对外公开"收藏数"（saves），热度指标使用点赞/评论/播放量。

## 安装

需要 Python 3.9+：

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m playwright install chromium
```

## 使用

```bash
.venv/bin/python app.py
```

浏览器自动打开 `http://127.0.0.1:5000`。

1. **登录**（首次）：到「设置」页点「打开浏览器登录」，在弹出的窗口中手动登录 Instagram。工具不接触、不保存密码，只把登录会话存到本地 `ig_state.json`（已 gitignore，不会上传）。
2. **建频道**：「设置」页配置主题频道（名称 + 英文标签集，如 `cats, dogs, pets`），默认已有一个「萌宠」频道。
3. **抓取**：顶栏选频道，点「🔍 抓取热门」，等 2–4 分钟，新视频进入「发现」页。
4. **下载**：「发现」页勾选（或全选）→「⬇️ 下载所选」；或直接在顶栏粘贴 IG 链接。
5. **发布**：「素材库」页预览视频、写文案、复制出处，到小红书/抖音 App 手动上传后回来点「📕 小红书」「🎵 抖音」标记状态。

## 目录说明

```
data/catchit.db    素材库数据库（视频、频道、设置）
data/thumbs/       封面图缓存
videos/<日期>/      下载的视频文件
ig_state.json      Instagram 登录会话（本地私密文件）
```
